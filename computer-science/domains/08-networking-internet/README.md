# Networking & Internet

**Purpose:** Layering, Ethernet, IP, routing, TCP, UDP, DNS, TLS, HTTP, congestion control, latency, and bandwidth.

## Guiding question
How does data travel between processes and machines? Where does network delay come from?

## Prerequisites
Binary representation and basic OS concepts.

## Suggested research path
Layered models → addressing and routing → transport → naming → security → application protocols.

## Engineering lens
Diagnose network latency, protocol behavior, reliability, and API performance.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
