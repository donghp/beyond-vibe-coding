# Memory Systems

**Purpose:** Registers, cache, cache lines, RAM, virtual memory, paging, TLB, locality, and memory consistency.

## Guiding question
Why can accessing data dominate computation? How do locality and working-set size influence performance?

## Prerequisites
Computer Architecture.

## Suggested research path
Memory hierarchy → cache → locality → virtual memory → address translation → coherence.

## Engineering lens
Diagnose cache behavior, memory pressure, allocation patterns, and data layout.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
