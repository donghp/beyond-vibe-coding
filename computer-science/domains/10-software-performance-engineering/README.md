**Purpose:** Measurement, profiling, benchmarking, latency distributions, throughput, utilization, queuing, optimization, and observability.

## Guiding question
Where is the bottleneck, and what evidence shows it?

## Prerequisites
Algorithms, architecture, memory, OS, databases, and networking.

## Suggested research path
Performance models → instrumentation → profiling → bottleneck analysis → controlled optimization → regression prevention.

## Engineering lens
Optimize the measured bottleneck, not code that merely looks expensive.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
