**Purpose:** Lexing, parsing, AST, type systems, intermediate representations, optimization, code generation, runtime, garbage collection, and JIT.

## Guiding question
How does source text become executable behavior? What guarantees do language and type systems provide?

## Prerequisites
Programming and discrete structures.

## Suggested research path
Language semantics → parsing → AST → type checking → IR → optimization → code generation → runtime.

## Engineering lens
Understand build pipelines, runtime overhead, language trade-offs, and debugging.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
