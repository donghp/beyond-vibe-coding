# Storage & Databases

**Purpose:** Storage engines, pages, row/column layouts, indexes, B-trees, transactions, isolation, query planning, logging, and replication.

## Guiding question
How do databases find, store, update, and protect data efficiently?

## Prerequisites
Data Structures & Algorithms and basic OS concepts.

## Suggested research path
Storage fundamentals → indexing → query execution → transactions → concurrency control → recovery.

## Engineering lens
Design schemas and indexes, explain query plans, and reason about data integrity.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
