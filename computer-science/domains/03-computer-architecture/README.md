# Computer Architecture

**Purpose:** CPU, instruction set architecture, registers, execution pipelines, branch prediction, superscalar execution, SIMD, and accelerators.

## Guiding question
How does source code become machine instructions? How does a processor execute them?

## Prerequisites
Binary representation and basic programming.

## Suggested research path
Data representation → machine instructions → datapath → pipeline → speculation → parallel execution.

## Engineering lens
Understand instruction cost, dependencies, vectorization, and hardware-specific bottlenecks.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
