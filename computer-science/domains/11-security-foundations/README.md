# Security Foundations

**Purpose:** Security properties, threat modeling, cryptography, authentication, authorization, key management, secure protocols, and secure design.

## Guiding question
What are we protecting, from whom, and under which assumptions?

## Prerequisites
Basic systems and networking.

## Suggested research path
Security principles → threat models → cryptographic building blocks → identity and access → protocol security → system design.

## Engineering lens
Define trust boundaries, least privilege, secure defaults, and verifiable controls.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
