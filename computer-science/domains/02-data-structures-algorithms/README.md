# Data Structures & Algorithms

**Purpose:** Arrays, linked lists, stacks, queues, hash tables, heaps, trees, graphs, sorting, searching, dynamic programming, and greedy algorithms.

## Guiding question
How does a structure organize information? What operations does it make efficient or expensive?

## Prerequisites
Computational Thinking.

## Suggested research path
Sequential structures → associative structures → trees and heaps → graphs → algorithmic strategies → complexity.

## Engineering lens
Choose structures based on workload, operation mix, memory layout, and correctness.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
