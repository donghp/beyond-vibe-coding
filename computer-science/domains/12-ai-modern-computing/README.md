**Purpose:** Linear algebra, probability, machine learning, neural networks, embeddings, transformers, GPUs, inference, RAG, agents, evaluation, and serving.

## Guiding question
How do modern AI systems represent, compute, retrieve, generate, and get evaluated?

## Prerequisites
Depth varies; common foundations include linear algebra, probability, algorithms, architecture, and systems.

## Suggested research path
ML foundations → neural computation → transformer architecture → inference → retrieval and agents → evaluation and production systems.

## Engineering lens
Build AI applications with measurable quality, explicit costs, system constraints, and human ownership.

## Research rules
- Begin with an explicit and answerable question.
- Explain intuition before technical detail, without changing the underlying science.
- Use authoritative sources and cite claims close to their use.
- Separate evidence, interpretation, and illustrative examples.
- Include experiments only when they can be described and reproduced honestly.
- State assumptions, trade-offs, and limits.
