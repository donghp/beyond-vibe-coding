# Editorial and Publication Standard

**Document ID:** BVC-RAG-STD-001  
**Version:** 1.0.0  
**Owner:** Dong Hong

## Editorial identity

Beyond Vibe Coding is practical, clear, human, and engineering-oriented. The series must explain mechanisms accurately without marketing hype or unnecessary jargon.

## Required article qualities

- A specific problem statement and learning objective.
- Correct terminology and a clear conceptual model.
- Explicit assumptions and scope.
- Technical claims supported by traceable evidence.
- Examples labelled as illustrative when they are not real policies or measurements.
- Limitations, failure modes, and trade-offs.
- A concise takeaway and forward link to the next relevant episode.

## Technical review checklist

- Are all mechanisms described accurately?
- Are retrieval, ranking, reranking, context assembly, and generation distinguished?
- Are vector, lexical, graph, and API-based methods used precisely?
- Are update, deletion, version, and permission lifecycle issues considered where relevant?
- Are model-specific and vendor-specific statements labelled?
- Are benchmarks reproducible and properly scoped?
- Are security boundaries and untrusted inputs addressed?
- Do figures agree with the text and use consistent terminology?

## Code policy

Include code when it demonstrates a concrete mechanism or enables a reproducible exercise. Code is not mandatory for a conceptual article. If code is included, provide dependency/version context, setup instructions, expected behavior, and limitations.

## Publication rules

- DEV.to is the primary English publication channel for this series.
- Viblo is the Vietnamese publication channel.
- Medium is a syndication/adaptation channel; use canonical metadata correctly for exact republication.
- Keep the GitHub repository as the supporting source and research archive.
- Do not claim a publication is live until its public URL is verified.
- Update publication metadata after each confirmed publication.
