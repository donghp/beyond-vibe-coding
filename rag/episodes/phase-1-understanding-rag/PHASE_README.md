# Phase I — Understanding RAG

**Episodes:** RAG-001 to RAG-004  
**Status:** Active  
**Owner:** Dong Hong · Beyond Vibe Coding

## Phase objective

Build the foundational mental model for retrieval-augmented generation and distinguish it from adjacent model adaptation and knowledge-access approaches.

## Episode sequence

- RAG-001 — What Is RAG? How AI Finds External Knowledge Before It Answers
- RAG-002 — Prompting vs. RAG vs. Fine-Tuning vs. Long Context
- RAG-003 — Parametric vs. External Knowledge
- RAG-004 — How a Question Flows Through RAG

## Phase-level outcome

Readers should be able to explain why a language model may need external knowledge, trace the three core RAG stages, identify the limits of retrieval augmentation, and make an initial architecture choice based on workload requirements.
