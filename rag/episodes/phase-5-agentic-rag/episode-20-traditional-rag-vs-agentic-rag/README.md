# RAG-020 — Traditional RAG vs. Agentic RAG

**Phase:** Agentic RAG  
**Status:** Planned · Research brief  
**Author:** Dong Hong · Beyond Vibe Coding

## Research purpose

Compare deterministic retrieve-then-generate pipelines with agentic planning, tool selection, iterative retrieval, and bounded execution.

## Learning objectives and research questions

1. What control decisions are delegated to an agent?
2. When does agentic orchestration add value?
3. What are the cost, latency, and reliability trade-offs?

## Core concepts

- Agentic RAG
- Planning
- Tool Selection
- Control Loop
- Bounded Execution
- Architecture Selection

## Technical treatment

Explain mechanisms before selecting tools. Distinguish deterministic workflows from agent-controlled execution. Make tool permissions, state boundaries, loops, budgets, stopping criteria, failure handling, and human oversight explicit. Compare graph and agent approaches against simpler baselines.

## Evidence requirements

Use original research, official framework documentation, security guidance, and reproducible evaluations. Distinguish framework-specific capabilities from general architecture principles. Do not invent benchmark values or production case studies.

## Status

This file is a research brief, not a completed manuscript or publication.
