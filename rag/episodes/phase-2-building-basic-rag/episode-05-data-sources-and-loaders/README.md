## Research purpose

Understand source systems, connectors, document loaders, file formats, extraction boundaries, and source ownership.

## Learning objectives and core questions

1. Which sources are authoritative?
2. How do loaders preserve identifiers and provenance?
3. How are incremental ingestion, retries, and source errors handled?

- Connectors
- Loaders
