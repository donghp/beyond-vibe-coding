# Episode Directory

Episodes are grouped by phase. Each episode folder should contain:

- `README.md`: research brief, objectives, scope, technical questions, evidence requirements, and publication record.
- `episode.yaml`: machine-readable metadata and status.
- Manuscript files only when an actual draft exists.
- Assets only when the source files and usage rights are recorded.

Status values:
- `planned`
- `researching`
- `drafting`
- `technical_review`
- `editorial_review`
- `ready_to_publish`
- `published`

Do not mark an episode as published without a verified public URL.

See [episodes-index.yaml](episodes-index.yaml) for the 24-episode index. Use [the episode template](../templates/EPISODE_TEMPLATE.md) and [metadata schema](../schemas/episode.schema.json).
