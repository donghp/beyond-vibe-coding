# RAG-012 — Dense Retrieval vs. BM25

**Phase:** Improving Retrieval  
**Status:** Planned  
**Version:** 0.1.0  
**Author:** Dong Hong · Beyond Vibe Coding

## Research purpose

Compare lexical retrieval and dense semantic retrieval at the mechanism and workload levels.

## Learning objectives and core questions

1. How does BM25 score terms?
2. How does dense retrieval represent semantic similarity?
3. Which query and corpus types favor each approach?

- BM25
- Lexical Retrieval
- Dense Retrieval
- Sparse Representation
