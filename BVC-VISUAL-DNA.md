# BVC VISUAL DNA V1.0

**The Visual Language of Beyond Vibe Coding — Living Book**

Status: **FOUNDATIONAL CREATIVE BASELINE**

---

## 1. Core Manifesto
> Human intention leads. AI capability follows. Real value emerges between them.

*Tiếng Việt:*
> Con người định hướng. AI khuếch đại năng lực. Giá trị thật được tạo ra ở điểm giao giữa hai bên.

---

## 2. Core DNA
- **DNA-01 HUMAN IN THE FRAME**: Emphasizing human agency and intent above raw machine generation.
- **DNA-02 DIRECTION OVER SPEED**: Valuing correct intent, task decomposition, and verification over reckless prompt speed.
- **DNA-03 CONTROLLED COMPLEXITY**: Restraining over-engineering, maintaining clean architectural boundaries.
- **DNA-04 HUMAN–AI TENSION**: The productive dialogue between human oversight and model capability.
- **DNA-05 EDITORIAL NEGATIVE SPACE**: Generous whitespace, clean typography, calm reading environments.
- **DNA-06 SIGNATURE HORIZON / TRAJECTORY**: Clear path from prototype to production.
- **DNA-07 REAL VALUE**: Focus on successful task completion and actual business/engineering value.

---

## 3. Visual Character
- Premium editorial
- Intelligent
- Cinematic but restrained
- Human-centered
- Technically credible
- Sophisticated
- Distinctive
- Memorable

**Strictly Avoid:**
- Generic AI robots
- Glowing brains
- Generic futuristic dashboards
- Cyberpunk aesthetics
- Excessive neon
- Stock-photo clichés
- Generic SaaS illustrations
- Generic enterprise flowcharts

---

## 4. Diagram & Workflow DNA
- Editorial geometry
- Restrained rounded nodes
- Thin connectors
- Deliberate whitespace
- Limited semantic color

**Conceptual Progression:**
INTENTION → CONTEXT → AI CAPABILITY → CONTROL → VERIFICATION → VALUE

---

## 5. Chapter Hero Image DNA
Every chapter hero must be:
- Chapter-specific
- Derived from the actual manuscript
- Human-centered
- Visually metaphorical
- Consistent with one book
- Distinctive from other chapters
- Free of AI-generated baked-in text
