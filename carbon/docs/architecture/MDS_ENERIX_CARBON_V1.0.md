# MDS ENERIX Carbon V1.0 Design System Specification

## Overview
MDS ENERIX Carbon V1.0 is the official enterprise design system governing the ENERIX Carbon Regulatory Carbon & GHG Engineering Platform.

## Core Architectural Contract
1. **Carbon Blue (#0284c7)** is the single primary visual accent for focus, active states, key interactive controls, and primary data highlights.
2. **Deep Navy (#0b192c / #1e293b)** is structural, providing authoritative framing for the header, sidebar, headings, and high-contrast metadata.
3. **Green (#16a34a / #15803d)** communicates strictly positive outcomes: reductions, passed validation gates, registered facilities, compliant temporal periods, and bitwise reproducibility.
4. **Amber (#d97706 / #b45309)** communicates warnings: transitional periods, pending verifications, multi-ministry regime conflicts, and unsegmented temporal straddles.
5. **Red (#dc2626 / #b91c1c)** communicates blocked states: fail-closed statutory blocks, data integrity errors, critical exceptions, and mandatory statutory deadlines.
6. **No Gradients** in normal product UI. All surfaces, cards, buttons, and headers must use solid, disciplined enterprise colors.
7. **Grid System**:
   - Desktop: 12 columns
   - Tablet: 8 columns
   - Mobile: 4 columns
8. **Dense, Readable Tables**: Enterprise data density with crisp borders, clear header rows, and zero page-level horizontal overflow. Local table horizontal scrolling only when required.
9. **Editorial GHG Callouts**: Curated callout boxes with solid left borders for Knowledge, Methodology circulars, and statutory disclosures.
10. **Typography**: High legibility with Inter and Be Vietnam Pro for Vietnamese Unicode diacritics, paired with monospace fonts for hashes, tax IDs, and emission factor units.
