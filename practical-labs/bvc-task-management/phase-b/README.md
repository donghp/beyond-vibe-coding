# Phase B — Build Your First Task

**Learning level:** Beginner\
**Status:** Planned — implementation and runtime evidence required

Phase B teaches the First Vertical Slice:

1. Create one task by entering only its title.
2. Save the task.
3. Reload or reopen the app in the same supported browser profile.
4. Confirm that the task remains available.

Individual lesson instructions will be finalized only after the relevant application behavior exists and has been tested. Do not describe a button, save mechanism, or storage behavior that has not been observed.
