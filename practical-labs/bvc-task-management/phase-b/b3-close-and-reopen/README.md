# Phase B · Lesson B3 — Close and Reopen

**Learning level:** Beginner\
**Status:** Planned — runtime persistence test required.

## Learning outcome

Reopen the application in the same supported browser profile and confirm that the saved task remains available.

## Required practical evidence

- The browser profile and app URL used for the test, without exposing private account information.
- The task before reload/reopen.
- The task after reload/reopen.
- The same task title visible after reopening.

This is the key persistence checkpoint. Do not mark it successful until it has actually been performed and documented.
