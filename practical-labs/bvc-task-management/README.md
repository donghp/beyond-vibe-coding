<a id="phase-b-beginner"></a>
## Phase B — Beginner

**Build Your First Task**

Continue with the [Phase B learning guide](phase-b/README.md):

1. [B1 — Create Your First Task](phase-b/b1-create-your-first-task/README.md) — enter a title, add the task, and see it in a list. The first version keeps tasks in page memory only.
2. [B2 — Save Your Task](phase-b/b2-save-your-task/README.md) — introduce browser storage only after the first-use data disclosure and the B2 implementation scope are approved.
3. [B3 — Close and Reopen](phase-b/b3-close-and-reopen/README.md) — verify that a saved task remains available in the same browser profile.
4. [B4 — Improve One Small Thing](phase-b/b4-improve-one-small-thing/README.md) — make one small, bounded improvement and check that the earlier flow still works.

**Important:** B1 and B2 teach two different ideas. B1 creates and displays a task temporarily. B2 teaches how to save it. A task disappearing after a page reload during B1 is expected, not a B1 failure.

<a id="phase-c-beginner-expansion"></a>
## Phase C — Beginner Expansion

**Make It Useful Every Day**

Open the [Phase C overview](phase-c/README.md) after Phase B:

- My Day and daily focus.
- My Tasks, search, filters, and task status.
- Projects and work areas.
- Starter Kits and reusable task templates.
- Settings, backup, and restore.
- Responsive layouts and everyday use.

These capabilities are introduced progressively. Follow the current Product/UX Decision Register and the approved task scope for each feature; a topic appearing in the curriculum does not mean it is already implemented or approved for immediate implementation.

<a id="phase-d-intermediate-advanced"></a>
## Phase D — Intermediate & Advanced

**Beyond Beginner**

Open the [Phase D overview](phase-d/README.md) when the Beginner learning path is complete.

**Intermediate:** relational data, PostgreSQL/Supabase, authentication, and data security.

**Advanced:** GitHub and source control, local development, testing, CI, deployment, and maintenance.

Phase D builds on the same BVC Task Management product. It is not a separate application and is not required to complete the Beginner lessons.

## Project boundaries

The Project Instructions and prompts in this directory belong only to BVC Task Management. They must not be copied from or applied to EFIN, ENERIXON FIN, or any unrelated project.

Practical Labs teach the reader. Product Definition, architecture baselines, UX decisions, approved Task Contracts, and Human Owner authorization remain the sources of authority for product implementation.

A lesson may explain a planned capability before it exists in the app. It must label that capability as planned and must never describe an untested interaction as if the reader has already seen it.
