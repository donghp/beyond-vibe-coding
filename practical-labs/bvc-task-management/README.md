# BVC Task Management — Learning Project

> **Quick navigation:** [Practical Labs Home](../README.md) · **Project Index** · [Phase A — Meet AI & Build Your First App](phase-a/README.md)

**Product:** BVC Task Management — A Simple Daily Work Manager  
**Learning program:** BEYOND VIBE CODING — Build & Learn  
**Primary learning environment in Phase A:** Google AI Studio (GAIS)

## Start here

Follow the four learning phases in order:

| Phase | Theme | Learning outcome |
|---|---|---|
| A — Beginner | Meet AI & Build Your First App | Open GAIS, create the blank app, inspect the scaffold, set Project Instructions, and communicate clearly with AI. |
| B — Beginner | Build Your First Task | Build the first small end-to-end task flow after its implementation scope is approved. |
| C — Beginner Expansion | Make It Useful Every Day | Add everyday task-management capabilities progressively. |
| D — Intermediate & Advanced | Beyond Beginner | Learn data, identity, security, source control, testing, deployment, and maintenance. |

## Project boundaries

The Project Instructions and prompts in this directory belong only to BVC Task Management. They must not be copied from or applied to EFIN, ENERIXON FIN, or any unrelated project.

Practical Labs teach the reader. Product Definition, architecture baselines, UX decisions, approved Task Contracts, and Human Owner authorization remain the sources of authority for product implementation.
