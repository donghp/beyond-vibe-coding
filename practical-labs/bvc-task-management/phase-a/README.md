## What you need for Phase A

- A modern web browser and internet access.
- Access to Google AI Studio.
- The BVC Task Management GAIS project created in A1.

You do not need programming experience, VS Code, GitHub, Localhost, a database, Supabase, or Authentication to complete the Beginner learning path in Phase A.

## Beginner boundary

Phase A is about learning to work with AI, not about implementing the product.

Do not add:
- Task forms, task lists, or task-management behavior.
- Task creation, editing, deletion, completion, or persistence.
- Databases, Supabase, APIs, or external services.
- User accounts, Authentication, or RLS.
- GitHub integration, local development, or deployment.

Prompt #0003 uses a task-feature scenario only to practice communication and planning. It is explicitly read-only and does **not** authorize implementation. Phase B is a separate product milestone with its own authorization and verification.
