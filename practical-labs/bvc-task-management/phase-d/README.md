# Phase D — Beyond Beginner

**Learning level:** Intermediate / Advanced\
**Status:** Planned — separate learning and implementation gates required

Phase D introduces the engineering concepts that become relevant as the product grows.

Planned lessons:

- D1 — Connect a Database
- D2 — Understand User Accounts
- D3 — Learn Data Ownership and Security
- D4 — Work with GitHub and Source Code
- D5 — Test, Deploy and Maintain the App

These topics are not Beginner prerequisites. Database, authentication, RLS, source control, local development, testing, and deployment must follow the current approved project baselines and their own task and verification gates.
