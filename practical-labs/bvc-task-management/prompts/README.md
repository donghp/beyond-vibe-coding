## Phase B lesson-embedded implementation requests

The first Phase B request is embedded in the B1 lesson so the learner can read the goal, scope, and verification steps together before copying it into GAIS.

| Lesson | Request | Scope |
|---|---|---|
| [B1 — Create Your First Task](../phase-b/b1-create-your-first-task/README.md#copy-and-paste-request) | B1 first-task request (embedded in the lesson) | One title input, Add action, visible in-memory list, and empty-title validation. No persistence or extra task features. |

**Execution rule:** Use the B1 request only when the approved B1 Task Contract is available in the working project and its exact file allowlist has been checked. If the Contract is unavailable or the requested change exceeds its scope, stop before editing.

The B1 request is lesson-embedded guidance. Do not allocate a new numbered Prompt ID from this table; numbered prompts remain controlled by the canonical Project Prompt Register.

## Prompt use rules

- Read the linked lesson before running a prompt.
- Copy the complete canonical prompt; do not shorten or silently rewrite it.
- Use the intended BVC Task Management GAIS project.
- Review the actual result and check it against the lesson's completion criteria.
- A successful AI response does not by itself prove application behavior, file integrity, build success, tests, or deployment.
- Do not allocate a new prompt ID without checking the project Prompt Index and applicable Task Prompt Standard.
