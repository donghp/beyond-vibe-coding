# Phase C — Make It Useful Every Day

**Learning level:** Beginner Expansion\
**Status:** Planned — each behavior requires implementation and verification

Phase C adds everyday value only after the First Vertical Slice is stable.

Planned lessons:

- C1 — Organize Tasks
- C2 — Mark Tasks as Complete
- C3 — Set a Due Date
- C4 — Find Tasks with Search and Filters
- C5 — Understand Browser Storage
- C6 — Backup and Restore Your Work

Do not teach a feature as working until the corresponding behavior has been implemented and tested. Browser storage must be described accurately: it is not cloud storage and does not automatically synchronize across devices.
