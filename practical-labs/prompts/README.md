## Authoring sequence

1. Select one learner outcome from the approved curriculum.
2. Confirm the current project state and authoritative sources.
3. Identify whether the lesson is read-only, instructional, or write-capable.
4. Prepare the prompt package when AI interaction is part of the lesson.
5. Apply the Prompt Readiness Gate.
6. Write the lesson using the current lesson template.
7. Add only authentic, relevant evidence.
8. Complete the review checklist.
9. Update the project lesson register and navigation.
10. Submit a branch and PR for Human Owner review.

## Prompt ID discipline

Prompt IDs are project-specific. Before assigning one:
- Read the current project prompt index.
- Search the repository for the proposed ID.
- Do not reuse an existing ID.
- Keep one canonical prompt file.
- Record the lesson association and contract/authorization reference.
- Mark read-only and write-capable prompts clearly.

## Prompt package quick checklist

- [ ] Objective is one bounded outcome.
- [ ] Project context and source of truth are explicit.
- [ ] Current state is inspected or identified as unknown.
- [ ] Technology facts are observed or marked unknown.
- [ ] Authorized paths and operations are explicit.
- [ ] Forbidden scope is explicit.
- [ ] Output and acceptance criteria are concrete.
- [ ] Verification evidence is defined.
- [ ] Stop conditions are clear.
- [ ] Human authority is preserved.
