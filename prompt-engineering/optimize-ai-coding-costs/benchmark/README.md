# Benchmark Lab

Use this directory to compare prompt and context optimization methods against a controlled baseline.

Start with [EXPERIMENT_PROTOCOL.md](./EXPERIMENT_PROTOCOL.md). Record one result per task using [benchmark-result.schema.json](../schemas/benchmark-result.schema.json).

Do not publish only the best run. Preserve failures, cache condition, model version, price version, timestamps, acceptance evidence and test outcomes.

The goal is to determine whether the same engineering outcome can be accepted at lower attributable API cost.
