# Optimize AI Coding Costs — DeepSeek + Codex Lab

> **Optimize engineering outcomes, not token volume.**
>
> A practical, evidence-led lab for connecting DeepSeek to Codex in VS Code and controlling AI-agent costs through prompt design, context selection, cache-aware request structure, scheduling, and outcome measurement.

This lab is part of the [Beyond Vibe Coding (BVC)](https://github.com/donghp/beyond-vibe-coding) engineering companion. It applies BVC's project-centric principles—bounded tasks, selected context, durable state, observed changes, and verification evidence—to the economics of AI-assisted software development.

## What this lab teaches

1. Configure DeepSeek as a model provider for the Codex IDE workflow in VS Code.
2. Understand the distinction between a local IDE/agent client and remote model inference.
3. Read input cache-hit, input cache-miss, and output token billing correctly.
4. Schedule deferrable work around provider-defined Peak and Off-peak windows.
5. Design stable prefixes and task-specific context without assuming cache hits are guaranteed.
6. Reduce irrelevant context, redundant tool output, unnecessary agent loops, and verbose output.
7. Measure cost per accepted engineering task rather than optimizing a token ratio in isolation.

## The real-world case study

The author's historical DeepSeek V4-Flash billing period (2026-08-29 through 2026-09-01) reconciles to:

- **417,153,568 total billed tokens**
- **962 API requests** across the two exported usage records
- **USD 5.014844192** reconciled API cost
- **413,217,024 input cache-hit tokens**
- **2,443,289 input cache-miss tokens**
- **1,493,255 output tokens**
- **99.4124% input cache-hit rate**

The CSV-derived results and limitations are documented in the [case study](./case-study/417-million-tokens-for-five-dollars.md). This is a historical, provider-billed usage result—not a universal price promise and not, by itself, proof of project quality or accepted deliverables.

## Critical terminology

- **Local IDE / agent client:** VS Code and the Codex extension operate in the developer's local environment and interact with the workspace and tools.
- **Remote inference:** DeepSeek receives API requests and performs model inference on provider infrastructure. This setup is not offline local model hosting.
- **Input cache hit:** Input tokens served from provider cache and billed at the cache-hit rate.
- **Input cache miss:** Input tokens not served from cache and billed at the cache-miss rate.
- **Output tokens:** Tokens generated by the model; these are billed separately.
- **Total billed tokens:** The sum of the above categories in the exported usage report. Do not describe all total tokens as newly submitted input.
- **Accepted engineering task:** A task whose defined acceptance criteria have been evaluated and accepted with appropriate evidence.

## Provider and model versioning

Provider APIs, model aliases, setup scripts, model IDs, prices, and Peak schedules can change. Before following setup or quoting prices, consult the current official DeepSeek documentation linked in the guides.

The case study refers to the historical model identifier and pricing recorded in the author's August–September 2026 CSV exports. Do not silently substitute current rates into historical calculations.
