|---|---|---|---|

## Publication guidance

- Keep the original screenshots unchanged as source evidence.
- Do not crop out relevant context in a way that changes the meaning.
- Do not add API keys, account identifiers or other private details.
- Keep billing calculations traceable to the exported CSV data.
- Treat the screenshots as supporting exhibits, not substitutes for the underlying data.

The article embeds both images using relative paths from the case-study Markdown file.
