# Prompt Engineering — AI Video Production Lab

This directory contains practical, project-based lessons for planning and producing AI-generated videos with consistent characters, controlled shots, and an editable post-production workflow.

## Featured practical lab

- [Create a Personal Cinematic Music Video with AI — “Don't Ask Me Why”](./dont-ask-me-why-ai-music-video/README.md)

The lab uses the eight-part case study **Don't Ask Me Why**  to teach an end-to-end workflow: avatar preparation, story development, shot planning, prompt writing, video generation, continuity control, review, and CapCut editing.

## Learning outcomes

By completing the lab, learners should be able to:

1. Prepare a reusable multi-angle character reference set.
2. Turn a story into a timeline of short, independently generatable clips.
3. Write shot-specific prompts with identity, action, camera, lighting, and output constraints.
4. Use actual previous-clip frames to preserve visual continuity.
5. Review generated footage and revise prompts based on observed defects.
6. Assemble a longer story and platform-specific edits in CapCut.

## Suggested path

1. Read the main lab from beginning to end.
2. Prepare the character references and production brief.
3. Review the eight-clip storyboard.
4. Generate clips one at a time, starting with Clip 01.
5. Extract and use actual ending frames when continuity matters.
6. Review each output before proceeding.
7. Assemble the approved clips and export platform versions.

## Important notes

- The example is a learning case study, not a guarantee that every AI tool will produce identical results.
- ElevenLabs and Veo are examples of video-generation tools. Features, models, reference-image limits, duration limits, pricing, and availability can change. Check the selected tool's current interface and documentation before generation.
- Use only images you own or have permission to use. Do not impersonate another person or upload private images without permission.
- Keep the original soundtrack separate when the workflow requires it; add licensed or owned audio during editing.
- A prompt cannot guarantee exact identity preservation or perfect anatomy. Use reference images, conservative actions, frame review, and regeneration where needed.
