# BVC Companion Core Specification Examples\n\nThese four YAML files are the linked worked examples for Context Manifest, Project State, Change Record, and Verification Evidence. They are stored separately from `examples/` because the existing Task Contract validator scans YAML files in that directory as Task Contracts. Keeping the folders separate preserves that validator's scope.\n\nAll values are synthetic teaching data, not proof of real execution. Run `python scripts/validate_core_specifications.py` from the repository root to validate this bundle against the existing Task Contract example.\n
